| Question | Result | Decision |
|---|---|---|

| Q5 most annoying | no free places 12, unclear schedule 11, cannot cancel 9, queue 6 | Live free places, class filter, cancel rule |
| Q6 preferred time | 18:00: 21, 20:00: 15, weekends 11, 12:00 10, 07:00 9 | Added 20:00 slot; 07:00 stays the weak slot |
| Q7 if class is full | choose another 24, skip 9, waiting list 6 | Waiting list is low priority |
| Q8 classes | Strength 24, Pilates 18, Cardio 18, Yoga 16 | Added Strength and Cardio classes |
| Q9 reminders (1-5) | 3.31 | Later, if time |
| Q10 waiting list | 3.33 | Later, if time |
| Q11 cancel up to 2 h | 3.51 | Done: cancelling closes 2 hours before class |
| Q12 trainer info | 4.18 (highest) | Done: Trainers page |
| Q13 online payment | 3.46 | Not now |
| Q14 history | 3.69 | Done: history in Profile |
| Q16 sign-up | many prefer Google or university account | Plan: Google / university login (Week 13-14) |
| Q17 price | up to $20: 17, $20-40: 12, $40-60: 8, more: 2 | Plans lowered to $25 / $65 / $240 |

Four checks (Lecture 11): features with high score and a clear problem are built first (trainer info, history, cancel rule, schedule filter).
